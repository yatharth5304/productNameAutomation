### 2026-08-21 (current)

- **Execution-time tracking**: wrapped the script entry point with `time.time()` to record start and end timestamps, printing total elapsed seconds after completion. This provides a zero‑risk way to monitor overall script duration without affecting any classification or matching logic.
- **Progress prints added**: `print("Loading workbook...")` before `load_workbook()` and `print("Workbook loaded.")` after; `print(f"Clearing {n} rows...")` before the CLEAR_EXISTING loop and `print("Cleared.")` after; `print(f"{n} rows to process. Starting classification...")` before the main loop. Eliminates all silent startup phases.

- **OPT-1 — token_spans() caching (2026-08-21)**: `token_spans(name)` was being called twice per row — once inside `exact_product_match` and again inside `fuzzy_product_match` — even though the result is identical for the same input. Both functions now accept an optional `precomputed_spans=None` parameter. The main loop computes `spans = token_spans(name)` once and passes it to both calls via `precomputed_spans=spans`. When `precomputed_spans` is `None` (e.g. called standalone), each function falls back to computing spans itself. Zero change to any matching logic, outputs, or ordering.
